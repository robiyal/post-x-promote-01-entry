One quote post on X promoting make.fun's make-your-own-bounty launch: a public post quoting make.fun's post, with its own photo (card.png), a make.fun mention and the entrant's play code in its text. The post's address is in POST.json, its exact text in POST_TEXT.txt; main.ts validates the entry (post URL shape, mention, play code, sponsor line, photo PNG) and writes a deterministic report to /output/entry.json.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
